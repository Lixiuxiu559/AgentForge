## 术语与概念

| 术语 | 本仓库含义 |
|---|---|
| Skill | SKILL.md 中的方法和边界，以及按需读取的 references、脚本和模板 |
| 技能真源 | skills 下维护的一份技能内容，供三端装配使用 |
| 宿主 | Codex、Claude Code 或 DSH；提供实际工具、权限及运行环境 |
| 通用子 Agent | 宿主创建的独立上下文；仍可能共享文件系统，不自带文件隔离 |
| Provider | DSH 的技能目录与正文读取适配，入口是 src/index.js |
| Candidate | list 返回的名称、描述、调用策略与文件定位信息，不包含技能正文 |
| resourceBase | get 返回的技能资源目录，与用户目标项目根不同 |
| 模块 | Wiki 的知识组织与路径映射单位，不强制等于语言包或运行服务 |
| passed / partial / issues / error | 工具的机械结果；分别表达声明范围内通过、覆盖不足、发现问题、执行失败 |
| 事实状态 | 默认模板的草稿、部分核验或已核验，与工具退出码分别记录 |
| 核验基线 | 本次结论适用的提交、版本或文件快照；不能证明已安装或已部署 |
| 项目约定优先 | 既有目录、术语和章节优先；未配置结构规范时使用 project 检查模式 |
| 新鲜度 | 来源、文档和配置是否仍匹配显式复核的内容快照；不按文档年龄或无关提交判定 |
| 复核声明 | updated、no-change 或 blocked，记录实际执行者、原因、证据和指纹；语义真实性仍需核实 |
| 同步检查门 | 对明确候选的配置、记录和文件快照检查状态与变更覆盖；与结构检查分别执行 |
| 讨论稿 | 目标流程与候选设计；未实施部分不能写成当前运行能力 |
