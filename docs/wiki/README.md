## 项目概览

AgentForge 是一份技能真源、多宿主使用的工程方法集合。当前提交含十个技能，分别维护在 skills 的直接子目录；Codex 和 Claude Code 通过各自插件清单发现技能，DSH 通过包内 provider 暴露候选和正文。宿主提供执行、独立上下文和并行能力。

仓库目前提供需求定义、调查、实施、评审和知识维护等方法。完整的需求到上线闭环仍有[设计讨论稿](../design/2026-10-16-lifecycle-workflow.md)，不能据此认为已有自动部署、持久调度或失败恢复引擎。

## 知识覆盖

本 Wiki 使用 modular 骨架，按四个能力模块组织，保留原有架构和发布文档作为详细来源。规则、代码映射及依赖只在需要时拆分，不为每个模块固定生成四文件。

功能基线为 3e5341d，包含新鲜度、复核记录和合并前检查；实际来源及文档指纹保存在项目复核记录中。三份清单版本均为 0.9.0，新增能力记录在 CHANGELOG 的 0.9.0 段落。关键源码、清单与技能边界已核对，实际本地验证结果见验证页。远端 Release、CI 和实际安装副本的状态须分别核对，不能从本地清单版本推导。
