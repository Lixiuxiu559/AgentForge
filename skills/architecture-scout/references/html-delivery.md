# HTML 报告交付

默认交付自包含的 HTML 文件。`candidate-report.md` 是内容检查结构，用于组织语义正文，不是要求输出 Markdown，也不把整篇 Markdown 原文放进 `pre` 中代替排版。

## 风格与阅读结构

使用主技能入口给出的蓝图母版，沿用其内联 CSS、Navy 侧栏、组件与响应式／打印样式，填入实际报告内容；用户明确指定其他风格时优先。

首屏概括调查范围、git 基线、结论、推荐候选及主要不确定性；提供章节和候选的稳定锚点。每个候选使用独立章节或卡片，证据强度、真实摩擦、反证和迁移风险默认可见，“维持现状／最小整理／结构性深化”用表格对照。长代码、历史明细和补充证据可折叠，完整内容仍保留在文件中。

零候选时直接展示结论、已查范围、支持维持现状的证据及调查限制，省略空候选卡片和推荐顺序。候选推荐只是建议，不以颜色、勾选或按钮状态暗示用户已经批准改造。

## 文件与离线阅读

使用 UTF-8、语义 HTML、内联 CSS 和系统字体，不依赖 CDN、远端字体或脚本。核心内容在标题、带唯一 `id` 的 `section`、列表和真实表格中，关闭 JS 仍可选择、搜索、复制和读取；JS 只增强阅读。

源码证据保留可定位的路径、行号和基线；可用时附有效相对链接，不把 `path:line` 伪装成不存在的文件 URL。代码片段放入转义后的 `pre/code`。图示如有，使用离线可见的内联 SVG 等形式，并保留文字说明与源码证据。

## 检查与交付

有可用浏览器或渲染工具时查看实际产物，检查桌面与窄屏的目录、锚点、表格、折叠和打印效果；宽表格／代码只在自身容器滚动，不产生整页水平溢出，打印时展开必要细节。无工具时静态核对内容完整性、结构与链接，并说明视觉未验证。

交付实际文件链接、关键结论和未验证项。修订时更新当前 HTML 正本，不手工维护重复 Markdown；用户明确指定其他格式或项目已有正本约定时优先，说明当前有效版本。
