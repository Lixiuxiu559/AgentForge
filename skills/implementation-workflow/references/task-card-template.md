# 子任务卡模板

派发实施任务时填写以下字段；无内容写「无」。

````markdown
### 任务 <编号>：<清晰的任务名称>

**执行上下文**

- 目标项目的绝对工作目录与代码基线
- 项目指令、需求和必要资源的绝对路径
- 必要 Skill / reference 的绝对路径；无法读取时附必要方法
- 只执行本任务，不重启编排

**执行规则**

- 先阅读现有实现和项目指令，复用接口与风格，不猜测 API
- 只修改任务范围，不擅自改变公共接口或引入无关重构、依赖
- 补充必要测试，失败时修复；不删除或弱化测试，不伪造结果
- 普通实现细节自行判断，缺少关键条件时向主 Agent 回报阻塞

**目标**

- 要完成什么，以及完成的判定是什么

**已确认的约束**

- 必须遵循的接口、数据模型、命名或错误处理约定
- 来自 spec / ADR / 用户确认的决策

**允许修改**

- src/feature/**
- tests/feature/**

**禁止修改**

- 其他并行任务负责的路径
- 公共配置与依赖清单（package.json / pom.xml / go.mod 等）
- 与本任务无关的模块

**前置依赖**

- 无
- 或：依赖任务 <编号> 已定义的 <接口 / 类型 / 文件>

**验收标准**

- 条件 1（可客观判断）
- 条件 2（可客观判断）

**验证命令**

```bash
<项目实际可运行的命令>
```

**返回格式**

- 状态：完成 / 部分完成 / 失败
- 修改了什么
- 修改了哪些文件
- 实际执行的验证命令与结果
- 是否存在未解决的问题
````
