---
name: research
description: 针对高可信度一手来源调查一个问题，并把发现以 Markdown 文件捕获到仓库中。当用户想要调研一个主题、收集文档或 API 事实，或把阅读工作委托给后台 agent 时使用。
---

启动一个**后台 agent** 去做调研，这样你能在它阅读时继续工作。

它的工作：

1. 针对**一手来源**调查问题——官方文档、源代码、spec、第一方 API——而不是关于它们的二手转述。把每个说法追溯到拥有它的来源。
2. 把发现写进一个 Markdown 文件，为每个说法标注其来源。
3. 把它存到仓库已经存放此类笔记的地方；匹配现有约定，如果没有约定，放到一个合理的地方并说明放在哪。
