# 为什么两轴不能合并

## 一条改动可以只过一条轴

- **完全符合规范，但做错了事** → Standards 通过，Spec 失败
- **完全满足需求，但破坏了项目约定** → Spec 通过，Standards 失败

如果合并成一个评分或一个排序，一条轴的通过会掩盖另一条的失败。作者看到"总体还行"就不会去修那个真正的问题。

## 具体禁止的做法

- 不要挑一个"跨轴最严重"的问题作为总结重点
- 不要把两轴的 finding 混在一个列表里按严重度排
- 不要给一个"总体通过/不通过"的结论

## 允许的做法

- 每个轴内部各自排序、各自指出最严重的一条
- 两个轴各自计数
- 在报告结尾并列展示两轴的结论

## 输出结构

```text
## Standards
  （这一轴的 finding，含该轴最严重的一条）

## Spec
  （这一轴的 finding，含该轴最严重的一条）

## 小结
  Standards：N 条
  Spec：M 条
```

两轴并列，不做合并裁决。
